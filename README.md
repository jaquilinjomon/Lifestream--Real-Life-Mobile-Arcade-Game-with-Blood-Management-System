# 🌐 Lifestream – Blood Donation Management System

**Lifestream** is a mini‑project developed as part of my MCA coursework.  
It is a **blood donation management system** that connects **donors, hospitals, and administrators** through a unified platform.  
The project also integrates a **donor game** to encourage participation and make the experience engaging.

---

## 🚀 Features
- 🩸 **Donor Portal** – Register, manage profiles, and receive real‑time alerts.
- 🏥 **Hospital Portal** – Submit blood requests and track donor availability.
- 🛠️ **Administrator Dashboard** – Validate requests and oversee activities.
- 🔔 **Real‑Time Notifications** – Urgent alerts using WebSocket integration.
- 🎮 **Gamified Donor Experience** – Interactive donor game for awareness.

---

## 🛠️ Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB  
- **Real‑Time Communication:** Socket.io  
- **Authentication:** JWT  
- **APIs:** RESTful services  

---

## 🎯 Objectives
- Simplify blood donation management.  
- Provide hospitals with quick access to donor data.  
- Encourage donor participation through gamification.  
- Ensure secure, scalable, and user‑friendly system design.
